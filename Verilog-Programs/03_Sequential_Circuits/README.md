# Sequential Circuits

This folder contains Verilog HDL implementations of sequential logic circuits. These circuits depend on both current inputs and previous states (memory).

## Experiments Included

- Flip-Flops
  - SR Flip-Flop
  - JK Flip-Flop
  - D Flip-Flop
  - T Flip-Flop
- Counters
  - Synchronous up & down Counters
  - Synchronous up-down Counter
  - Johnson Counter
  - Ring counter
- Registers
  - Shift Registers
  - Serial-In Serial-Out (SISO)
  - Serial-In Parallel-Out (SIPO)
  - Parallel-In Serial-Out (PISO)
  - Parallel-In Parallel-Out (PIPO)

Each experiment contains:
- Verilog source code
- Testbench code
- Short explanation of the design and working
