# Combinational Circuits

This folder contains Verilog HDL implementations of fundamental combinational logic circuits used in digital design. These circuits produce outputs based only on the current inputs.

## Experiments Included

- Code Converters
  - Binary to BCD Converter
  - Binary to Grey converter
  - BCD to Excess-3 converter
- Multiplexers
  - 2x1 Multiplexer
  - 4x1 Multiplexer
- Demultiplexers
  - 1x2 Demultiplexer
  - 1x4 Demultiplexer
- Decoders
  - 2-to-4 Decoder
  - 3-to-8 Decoder
- Encoders
  - Priority Encoder
  - 8-to-3 Encoder

Each experiment contains:
- Verilog source code
- Testbench code
- Short explanation of the design and working
