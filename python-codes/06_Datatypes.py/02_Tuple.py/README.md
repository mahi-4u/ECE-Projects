# Tuples in Python

## Introduction

A tuple is an ordered and immutable collection of elements. Once a tuple is created, its elements cannot be modified.

---

## Why This Topic Is Important

Tuples are useful when data should remain constant.

They are commonly used for:

- Storing fixed data
- Returning multiple values from functions
- Protecting data from modification
- Representing records

---

## Types / Syntax

### Creating a Tuple

```python
numbers = (10, 20, 30)
single = (5,)
mixed = (1, "Mahesh", 3.14)
```

### Accessing Elements

```python
numbers[0]
numbers[-1]
```

### Slicing

```python
numbers[1:3]
```
