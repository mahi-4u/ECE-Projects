# Sets in Python

## Introduction

A set is an unordered collection of unique elements. Sets automatically remove duplicate values and are useful for mathematical set operations.

---

## Why This Topic Is Important

Sets are useful for:

- Removing duplicates
- Checking membership efficiently
- Performing union and intersection
- Comparing collections of data

---

## Types / Syntax

### Creating a Set

```python
numbers = {10, 20, 30}
```

### Empty Set

```python
empty_set = set()
```

### Adding Elements

```python
numbers.add(40)
```
