# Lists in Python

## Introduction

A list is an ordered and mutable collection of elements. Lists can store multiple values of different data types in a single variable.

---

## Why This Topic Is Important

Lists are useful for:

- Storing multiple values
- Updating data
- Iterating through collections
- Sorting and searching
- Solving many real-world problems

---

## Types / Syntax

### Creating a List

```python
numbers = [10, 20, 30]
names = ["Mahesh", "Python", "GitHub"]
mixed = [10, "Mahesh", 3.14]
```

### Accessing Elements

```python
numbers[0]
numbers[-1]
```

### Slicing

```python
numbers[1:4]
```
