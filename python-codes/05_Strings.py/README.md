# Strings in Python

## Introduction

A string is a sequence of characters enclosed in single quotes, double quotes, or triple quotes. Strings are used to store and manipulate text data.

---

## Why This Topic Is Important

Strings are used in almost every Python program.

Common uses include:

- Storing names and messages
- Processing text
- Validating user input
- Searching and replacing text
- Reading and writing files

---

## Types / Syntax

### Creating Strings

```python
name = "Mahesh"
message = 'Hello'
text = """Multi-line string"""
```

### Accessing Characters

```python
name[0]
name[-1]
```

### Slicing

```python
name[0:3]
name[::-1]
```
