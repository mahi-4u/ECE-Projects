# Conditional Statements in Python

Conditional statements are used to make decisions in a program. They allow Python to execute different blocks of code based on whether a condition is `True` or `False`.

---

## Why Conditional Statements Are Important

Conditional statements help us:

- Check conditions
- Make decisions
- Control program flow
- Build real-world applications

Examples:
- Checking if a number is even or odd
- Finding the largest number
- Assigning grades
- Validating user input

---

## Types of Conditional Statements

### 1. `if`
Executes a block only if the condition is true.

```python
if x > 0:
    print("Positive number")
```

### 2. `if-else`
Chooses between two blocks.

```python
if x % 2 == 0:
    print("Even")
else:
    print("Odd")
```

### 3. `if-elif-else`
Checks multiple conditions.

```python
if marks >= 90:
    print("A Grade")
elif marks >= 75:
    print("B Grade")
else:
    print("C Grade")
```

### 4. Nested `if`
Uses one `if` inside another.

```python
if age >= 18:
    if age >= 21:
        print("Adult")
```

### 5. Short-hand `if`
Single-line `if`.

```python
if x > 5: print("x is greater than 5")
```
